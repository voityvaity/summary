# egorfenin.ru — интерактивное резюме

Персональный сайт Егора Фенина, Python Developer.

- Сайт: [egorfenin.ru](https://egorfenin.ru)
- GitHub: [voityvaity](https://github.com/voityvaity)
- Backend-проекты: [Foodgram](https://github.com/voityvaity/foodgram), [Kittygram](https://github.com/voityvaity/kittygram_final), [Taski](https://github.com/voityvaity/taski-docker) и [Final Defence Coach](https://github.com/voityvaity/tngimpact-final-defence-coach)

## Что реализовано

- интерактивная обложка и адаптивное резюме;
- поддержка клавиатуры и режима уменьшенной анимации;
- автоматическое скачивание актуального DOCX;
- ссылки на контакты, GitHub и проекты;
- адаптивная вёрстка для телефона и компьютера.

## Стек

React, TypeScript, Vinext, Vite, CSS. Продакшен развёрнут на Amvera, домен подключён отдельно.

## Локальный запуск

Требуется Node.js 22.13 или новее.

```bash
npm install
npm run dev
```

Проверка перед публикацией:

```bash
npm test
```

## Повторное развёртывание на Amvera

Статус: **восстановлено, работает по подтверждению владельца (23.10.2026)**. Источник: логи и проверка развёртывания 22–23.10.2026, настройки [`amvera.yml`](amvera.yml).

- **Среда:** Node.js **22.13+**, сборка `npm run build`, запуск `npm run start`, порт **3000**. Если в логе указано `Node.js v20` и ошибка `node:fs/promises` / `glob`, Amvera использует неподходящую версию Node; проверь именно применённую конфигурацию.
- **Обновление сайта:** после `push` в GitHub выполните в Amvera **«Пулл»**, проверьте наличие нового кода, затем **«Собрать»**. Один перезапуск обновлённый код не загрузит. Не используйте «Форс пулл» при несохранённых правках в Amvera.
- **Домен:** хостинг сайта — **Amvera**; отдельный платный хостинг REG.RU не требуется. Для `egorfenin.ru` DNS управляется в REG.RU: значения записей **A** и **TXT `_amvera`** берите из текущего интерфейса Amvera. После смены DNS-серверов распространение записей может занять до 24 часов; затем подтвердите домен и HTTPS.
- **Диагностика:** сначала проверяйте технический адрес Amvera, статус реплик и логи приложения/системы. Ошибки `amvera-artifacts-s3` и `PersistentVolumeClaims` относятся к инфраструктуре; `glob` при Node 20 — к версии среды. После исправления конфигурации и привязки домена может потребоваться **перезапуск приложения**.

## Структура

- `app/page.tsx` — содержание и интерактивность;
- `app/globals.css` — визуальное оформление и адаптивность;
- `app/layout.tsx` — метаданные страницы;
- `public/resume-egor-fenin-2026.docx` — скачиваемая версия резюме;
- `amvera.yml` — настройки сборки и запуска на Amvera.

Секреты и локальные файлы окружения не должны попадать в репозиторий.
